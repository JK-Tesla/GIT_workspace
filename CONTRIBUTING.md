# Соавторство / Contributing Guide

Мы рады любым улучшениям этого руководства по Codeium! 

### Как предложить изменения:
1. Сделайте **Fork** проекта.
2. Создайте ветку для исправлений (`git checkout -b fix/guide-update`).
3. Внесите изменения и сделайте понятный коммит.
4. Откройте **Pull Request**.

Пожалуйста, пишите простым языком и проверяйте работоспособность горячих клавиш.
